# Description

Basic RGBA colour. Numbers range from 0 to 255 (or 0xFF in hexadecimal) and are
linear, not sRGB.

# Members

| Type    | Name    | Description                |
|---------|---------|----------------------------|
| Integer | `red`   | Rectangle's right radius.  |
| Integer | `green` | Rectangle's top radius.    |
| Integer | `blue`  | Rectangle's left radius.   |
| Integer | `alpha` | Rectangle's bottom radius. |
