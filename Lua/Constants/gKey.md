Bit-masks of various keys. Used with `gKeyMC`, `gKeyTrg`, and co.

| Name          | Action           |
|---------------|------------------|
| `gKeyJump`    | Jump.            |
| `gKeyShot`    | Shoot.           |
| `gKeyArms`    | Next weapon.     |
| `gKeyArmsRev` | Previous weapon. |
| `gKeyItem`    | Inventory.       |
| `gKeyMap`     | Map.             |
| `gKeyPause`   | Pause.           |
| `gKeyStrafe`  | Strafe.          |
| `gKeySkip`    | Skip cutscene.   |
| `gKeyOk`      | Enter menu.      |
| `gKeyCancel`  | Exit menu.       |
| `gKeyLeft`    | Left.            |
| `gKeyUp`      | Up.              |
| `gKeyRight`   | Right.           |
| `gKeyDown`    | Down.            |
