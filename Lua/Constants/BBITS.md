Bullet traits.

# `BBITS_BREAKBLOCK`

Appears to be unused.

# `BBITS_SHOWER`

Appears to be unused.

# `BBITS_THROWMAP`

Bullet goes through map; will not collide with level tiles.

# `BBITS_REPLACE`

When colliding with a tile, reposition the bullet to be positioned exactly
against the tile, so that the effect does not appear to be pushed into it.

# `BBITS_NOBREAK`

Do not be destroyed when colliding with an enemy that blocks attacks.

# `BBITS_BLOCKBUSTER`

Destroyed blocks with the attribute `ATRB_SNACK`. Also destroys self.

# `BBITS_BLOCKERASE`

Destroyed blocks with the attribute `ATRB_SNACK`. Does not destroy self.

# `BBITS_NOBANISH`

Do not be destroyed when colliding with an enemy that blocks attacks.
