Second player's outfit enumerations.

# `P2_OUTFIT_OG`

Alternate-resolution version of the regular outfit:
- Classic when using Cave Story+ graphics.
- Cave Story+ when using Classic graphics.

# `P2_OUTFIT_NORMAL`

Regular outfit.

# `P2_OUTFIT_EASY`

Easy mode outfit.

# `P2_OUTFIT_HARD`

Hard mode outfit.

# `P2_OUTFIT_HALLOWEEN`

Halloween outfit.

# `P2_OUTFIT_CHRISTMAS`

Christmas outfit.

# `P2_OUTFIT_CURLY_NORMAL`

Curly's regular output.

# `P2_OUTFIT_CURLY_EASY`

# `P2_OUTFIT_CURLY_HARD`

Curly's hard mode output.

# `P2_OUTFIT_CURLY_CHRISTMAS`

Curly's Christmas output.

King.

# `P2_OUTFIT_SUE`

Sue.

# `P2_OUTFIT_BOOSTER`

Professor Booster.

# `P2_OUTFIT_TOROKO`

Toroko.

# `P2_OUTFIT_KILLER_ROBOT`

arena.
