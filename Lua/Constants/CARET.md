'カレット' ('ka-ret-to'). You tell me what that's supposed to mean.

Caret IDs.

These are similar to particle effects, in that they are decorative entities
which do not interact with anything.

# `CARET_SPLASH`

"Splash".

Water droplet. Created by jumping into water.

# `CARET_SMOKE`

Dissipating circle/diamond. Created by when a bullet is blocked, and when some
NPCs are destroyed.

# `CARET_FLASH`

Dissipating star. Created by various bullets.

# `CARET_XXXXX2`

Unused. Internally labelled 'snake', and uses sprites which greatly resemble
the Snake's projectiles, so this may have been an early prototype for the
bullet subsystem.

# `CARET_ZZZ`

The 'Z's that appear when a character is sleeping.

# `CARET_BOTAN`

Unused duplicate of the also-unused `CARET_XXXXX2`.

# `CARET_MISSILE`

Missile smoke trail particle.

# `CARET_WATERDEAD`

The player character, drowned. Was used in older version of the game, but has
since been replaced by making the player character itself display this sprite
instead of using a caret.

# `CARET_QUESTION`

The '?' that appears when the player character is examining something.

# `CARET_LEVELUP`

The 'LEVEL UP!' and 'LEVEL DOWN' text that appears when gaining or losing EXP.

# `CARET_DAMAGE`

Damage particle that appears when shooting an enemy.

# `CARET_BIGSMOKE`

Remember the name!

Big flashing circle, created when an enemy when an NPC is destroyed.

# `CARET_SMALLSTAR`

Tiny star that appears when the player bumps their head on the ceiling.

# `CARET_BOM`

Unused gigantic explosion effect.

Uses outdated sprite coordinates, which appear to have been intended for those
five large circle sprites which sit unused at the bottom of `Caret.X.png`.

# `CARET_BUBBLIN`

Dissipation effect used by level 1 and level 2 Bubbline bullets.

# `CARET_EMPTY`

'EMPTY!' text which appears when attempted to fire a weapon with no ammunition.

# `CARET_PUSHJUMPKEY`

Unused caret for displaying the equally-unused 'PUSH JUMP KEY!' sprite.

# `CARET_SANDDUST`

Little dust cloud that is created when walking around Sand Zone.
