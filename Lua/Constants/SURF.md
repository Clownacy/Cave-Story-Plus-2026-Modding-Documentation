The game internally keeps an array of textures, and these enumerations describe
each entry in that array. These are useful for making NPCs use textures besides
the current stage's NPC sprite-sheet.

# `SURF_TITLE`

Title screen's sprite-sheet, `Title.X.png`.

# `SURF_PARTS`

Stage's tile-sheet, `Stage/PrtXXXX.X.png`.

# `SURF_FADE`

Screen-fade sprite-sheet, `Fade.X.png`.

# `SURF_ITEMIMAGE`

Inventory item sprite-sheet, `ItemImage.X.png`.

# `SURF_ARMS`

Weapon sprite-sheet, `Arms.X.png`.

# `SURF_ARMSIMAGE`

Weapon HUD/inventory sprite-sheet, `ArmsImage.X.png`.

# `SURF_STAGEIMAGE`

Teleporter menu sprite-sheet, `StageImage.X.png`.

# `SURF_LOADING`

Loading-screen sprite-sheet, `Loading.X.png`.

# `SURF_MYCHAR`

Player sprite-sheet, `MyChar/MyChar01.X.png`.

# `SURF_BULLET`

Bullet sprite-sheet, `Bullet.X.png`.

# `SURF_CARET`

Caret sprite-sheet, `Caret.X.png`.

# `SURF_NPC_SYMBOL`

Common inanimate NPC sprite-sheet, `Npc/NpcSym.X.png`.

# `SURF_NPC_ENEMY`

Stage's NPC sprite-sheet, `Npc/NpcXXXX.X.png`.

# `SURF_NPC_BOSS`

Stage's boss sprite-sheet, `Npc/NpcXXXX.X.png`.

# `SURF_NPC_REGULAR`

Common living NPC sprite-sheet, `Npc/NpcRegu.X.png`.

# `SURF_CARET2`

Caret glow sprite-sheet, `Caret2.X.png`.

# `SURF_BULLET2`

Bullet glow sprite-sheet, `Bullet2.X.png`.

# `SURF_TEXTBOX`

Text box sprite-sheet, `TextBox.X.png`.

# `SURF_BACK`

Background sprite-sheet, `bkXXXX.X.png`.

# `SURF_ILLUST`

Current credits illustration, `CREDITXX.X.png`.

# `SURF_CASTS`

Credits cast-member sprite-sheet, `casts.X.png`.

# `SURF_LIGHT`

Omnidirectional light sprite, `light.X.png`.

# `SURF_LIGHT_DIR`

Directional light sprite, `light_dir.X.png`.

# `SURF_UI`

Main menu's user interface sprite-sheet, `UI.X.png`.

# `SURF_BUTTONS`

Controller button sprite-sheet, `buttons.X.png`.

# `SURF_UI_MUSIC`

# `SURF_BACK2`
