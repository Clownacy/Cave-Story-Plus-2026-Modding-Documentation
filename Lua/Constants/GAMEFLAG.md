Game state bit-flags.

# `GAMEFLAG_ACTION`

Player, NPCs, bosses, and so on are being updated.

# `GAMEFLAG_KEYCONTROL`

Player controls enabled.

# `GAMEFLAG_TEXTSCRIPT`

Text script (TSC) is current running.

# `GAMEFLAG_ENDING`

Credits are playing.

# `GAMEFLAG_ITEM_PAGE`

Multi-page invetory item description is active.

# `GAMEFLAG_CUTSCENE_SKIP`

Cutscene is currently being fast-forwarded.
