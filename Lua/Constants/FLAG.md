Reports collisions with the map.

# `FLAG_HIT_LEFT`

Hit wall to the left.

# `FLAG_HIT_TOP`

Hit ceiling.

# `FLAG_HIT_RIGHT`

Hit wall to the right.

# `FLAG_HIT_BOTTOM`

Hit floor.

# `FLAG_HIT_LDOWN`

Hit sloped floor to the left.

Used only by bullets.

# `FLAG_HIT_RDOWN`

Hit sloped floor to the right.

Used only by bullets.

# `FLAG_HIT_LUP`

Hit sloped ceiling to the left.

Used only by bullets.

# `FLAG_HIT_RUP`

Hit sloped ceiling to the right.

Used only by bullets.

# `FLAG_HIT_X`

All of the above bit-flags combined, used to check if any of them are set.

# `FLAG_HIT_WATER`

Hit water.

# `FLAG_HIT_BLOCK`

Hit a block with attribute `ATRB_BLOCK`, `ATRB_SNACK`, or `ATRB_EBLOCK`.

Used only by bullets.

# `FLAG_HIT_DAMAGE`

Hit a block with attribute `ATRB_DAMAGE` or `ATRB_DAMAGE_W`.

Used only by player.

# `FLAG_RED_WATER`

Hit a block with attribute `ATRB_DAMAGE_W`.

# `FLAG_HIT_VECT_LEFT`

Hit a block with attribute `ATRB_LEFT`.

# `FLAG_HIT_VECT_UP`

Hit a block with attribute `ATRB_UP`.

# `FLAG_HIT_VECT_RIGHT`

Hit a block with attribute `ATRB_RIGHT`.

# `FLAG_HIT_VECT_DOWN`

Hit a block with attribute `ATRB_DOWN`.

# `FLAG_SET_TRI_E`

Hit a block with attribute `ATRB_TRI_E`.

# `FLAG_SET_TRI_F`

Hit a block with attribute `ATRB_TRI_F`.

# `FLAG_SET_TRI_G`

Hit a block with attribute `ATRB_TRI_G`.

# `FLAG_SET_TRI_H`

Hit a block with attribute `ATRB_TRI_H`.
