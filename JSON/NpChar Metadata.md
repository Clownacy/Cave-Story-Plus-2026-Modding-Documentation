# `bits`

Type: BITS (See `BITS.md` for more information.)

Bitfield describing various properties of the NPC.


# `life`

Type: Integer

How much health the NPC has.


# `surf`

Type: SURF (See `SURF.md` for more information.)

Which surface (sprite-sheet) the NPC should use.


# `destroy_voice`

Type: Integer

Numerical ID of sound to play when destroyed.


# `hit_voice`

Type: Integer

Numerical ID of sound to play when hit.


# `size`

Type: Integer

NPC's size (see `NPCSIZE.md`).


# `exp`

Type: Integer

How much EXP to drop when destroyed.


# `damage`

Type: Integer

How much damage to inflict upon contact.


# `hit`

Type: RANGE (See `RANGE.md` for more information.)

NPC's hitbox.


# `hit`

Type: RANGE (See `RANGE.md` for more information.)

NPC's hitbox.


# `view`

Type: RANGE (See `RANGE.md` for more information.)

Dimensions related to the NPC's sprite. Used to centre the sprite over its
position coordinate.


# `light`

Type: LIGHT (See `LIGHT.md` for more information.)

Light emitted by NPC.
