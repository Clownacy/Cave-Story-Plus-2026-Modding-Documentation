# `__comment`

Type: String

A comment extracted from the game's source code which describes the associated
caret.


# `view_left`

Type: Integer

Horizontal offset of the caret's sprite. Used to centre the sprite over its
position coordinate.


# `view_top`

Type: Integer

Horizontal offset of the caret's sprite. Used to centre the sprite over its
position coordinate.


# `glow`

Type: Boolean

Whether the caret should emit light or not.


# `light`

Type: LIGHT (See `LIGHT.md` for more information.)

Metadata of the light which the caret emits.
